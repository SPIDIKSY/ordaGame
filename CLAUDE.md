# Правила для работы над игрой «Бесконечная орда»

Эти правила читает каждая сессия Claude, которая открывает этот репозиторий.

## Главное: не тратить кредиты Netlify на мелочи

Сайт https://ordapiva.netlify.app живёт на бесплатном тарифе Netlify:
300 кредитов в месяц, **каждая выкладка сайта стоит 15 кредитов**.
Когда кредиты кончаются, Netlify ставит сайт на паузу до следующего месяца —
игра перестаёт открываться у всех.

Поэтому:

1. **Ничего не заливать на GitHub без прямой просьбы хозяина** («заливай», «выкладывай»).
   Мелкие правки копим в локальных коммитах на рабочей ветке.
2. **Не создавать и не сливать pull request в `main`**, пока хозяин не попросил.
3. Когда хозяин сказал «заливай» — всё накопленное уходит **одним** слиянием в `main`.
4. **Сайт пересобирается, только если в описании коммита в `main` есть метка `[deploy]`.**
   Без метки Netlify сборку пропускает — это бесплатно
   (проверка записана в `netlify.toml`, строка `ignore`).
   - Нужно выложить игру → в заголовке коммита слияния пишем `[deploy]`,
     например: `Новые герои и баланс (#14) [deploy]`.
   - Правка только в описаниях, README, правилах — метку **не** ставим.
5. Перед выкладкой проверить, что всё работает: `npm test` и `npm run build`.

## Как устроен проект (коротко)

- Игра: React + Vite, движок на canvas — `src/game/run/*` (логика), `src/game/render/*` (рисование).
- Сервер (аккаунты, лидерборд, защита от читов): Node.js, `server/*`.
  На Netlify работает как функция `netlify/functions/api.mjs`, данные — в Netlify Blobs.
- Урон оружия считается в одном месте: таблица `WINFO` и функция `weaponNums` в `src/game/data.js`.
  Урон везде показывается **за один удар, целым числом, без «×»**.
