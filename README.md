# Бесконечная орда

Браузерная мини-игра в жанре «выживание против орды»: выбери героя, бегай по ночной поляне,
уворачивайся от волн монстров, собирай опыт и сундуки, прокачивай оружие и реликвии.
Шесть героев, включая Пивного кота. Каждые 2,5 минуты приходит босс, а с 8:00 начинается Волна смерти.

Сделано на **React + Vite**. Сама игра рисуется на `<canvas>`, а меню, HUD и экраны — React-компоненты.

## Как запустить у себя (Windows)

1. Установи [Node.js](https://nodejs.org/) версии **22.13 или новее** (подойдёт LTS 22 или 24).
2. Открой папку проекта в **PowerShell** (или в терминале VS Code).
3. Один раз установи зависимости:
   ```powershell
   npm install
   ```
4. Запусти игру вместе с сервером:
   ```powershell
   npm run dev
   ```
   Открой в браузере адрес из терминала (обычно `http://localhost:5173`).
   Изменения в коде сразу видны в браузере.

База данных создастся сама в файле `data/orda.db` (это обычный SQLite).

## Как выложить на Netlify (рекомендуется)

Netlify сам соберёт игру и запустит API. Данные (аккаунты, рекорды) хранятся в **Netlify Blobs** —
это встроенное хранилище Netlify, его не нужно отдельно подключать.

1. Зарегистрируйся на [netlify.com](https://www.netlify.com) (можно через GitHub).
2. **Add new project → Import an existing project → GitHub** и выбери репозиторий `ordaGame`.
3. Ветка — `main`. Остальные настройки Netlify возьмёт из файла `netlify.toml`
   (сборка `npm run build`, папка `dist`, API в `netlify/functions`).
4. Нажми **Deploy**. Через 1–2 минуты появится ссылка вида `https://что-то.netlify.app` — игра готова.
5. Название сайта можно поменять: **Project configuration → Change project name**.

Каждый раз, когда в ветку `main` попадают изменения, Netlify сам пересобирает игру.
Посмотреть сохранённые данные: в панели Netlify раздел **Blobs**, хранилище `orda`.

## Как выложить на свой сервер (VPS)

Если когда-нибудь захочешь свой сервер вместо Netlify (данные будут в SQLite-файле `data/orda.db`):

```bash
npm ci            # установить зависимости
npm run build     # собрать игру в папку dist
npm start         # запустить: игра + API на порту 3000
```

- Другой порт: `PORT=8080 npm start` (Linux) или `$env:PORT=8080; npm start` (PowerShell).
- Для HTTPS поставь перед игрой nginx или Caddy и добавь переменную `TRUST_PROXY=1`.
- Резервная копия — файл `data/orda.db`.

## Аккаунты, лидерборд и защита от читов

- Регистрация по логину и паролю. Пароли хранятся только в виде хеша (scrypt). Вход защищён от перебора.
- Ник выбирается один раз при регистрации, сменить его нельзя. Два одинаковых ника не бывает:
  регистр, пробелы, `_`, `-` не важны, а латинские буквы, похожие на русские, считаются одинаковыми
  (`Bacя` = `Вася`). Свободен ли ник — видно прямо во время ввода.
- Гость может играть сразу, но в лидерборд попадают только забеги с аккаунтом.
- Лидерборд: лучший забег каждого игрока, сначала по времени, потом по убийствам, потом по очкам. Есть вкладки по героям.
- Защита от читов (`server/anticheat.js`): сервер сам засекает начало забега, игра отчитывается каждые 15 секунд,
  и сервер отклоняет всё неправдоподобное: время больше реального, «скачки» убийств, слишком высокий уровень,
  лишних боссов, забег без отчётов. Очки считает сервер. Полностью защитить браузерную игру нельзя
  (её код у игрока), но подделать результат «в лоб» больше не получится.
- Проверки сервера: `npm test`.

## Управление

- **Телефон:** тяни кружок-джойстик внизу экрана.
- **Компьютер:** `WASD` или стрелки — бег, `Esc` / `P` — пауза,
  `1` `2` `3` — выбор карточки уровня, `R` — переброс, `Enter` — начать игру.

## Где что лежит

```
src/
  App.jsx                 — главный компонент: canvas + экраны
  styles.css              — все стили
  ui/                     — экраны и HUD (React)
    StartScreen.jsx         меню и выбор героя (с живым превью)
    Hud.jsx                 уровень, здоровье, таймер, слоты
    LevelUpScreen.jsx       карточки нового уровня
    ChestScreen.jsx         открытие сундука
    PauseScreen.jsx, DeadScreen.jsx
  net/                    — запросы к серверу и аккаунт игрока
  game/
    data.js               — БАЛАНС: оружие, предметы, реликвии, герои, враги
    engine.js             — логика: движение, оружие, враги, уровни, сундуки
    render.js             — отрисовка мира на canvas
    store.js              — мостик между игрой и React
    gfx.js, icons.js      — инструменты рисования и SVG-иконки
    sprites/
      heroes.js           — герои и анимация оружия в руках
      enemies.js          — монстры и боссы
      world.js            — сундуки, кристаллы, бонусы, трава
      biomes.js           — местности: лес, кладбище, пустоши, тундра, пекло
server/
  api.js                  — API: регистрация, вход, забеги, лидерборд (один код для Netlify и своего сервера)
  anticheat.js            — проверки результатов
  kv-blobs.js             — хранилище на Netlify (Netlify Blobs)
  kv-sqlite.js            — хранилище локально и на своём сервере (SQLite)
  index.js                — запуск на своём сервере (npm start)
netlify/functions/api.mjs — API на Netlify
netlify.toml              — настройки сборки для Netlify
```

Хочешь поменять баланс (урон, здоровье героев, скорость врагов) — начинай с `src/game/data.js`.

## Для разработки

В режиме `npm run dev` в консоли браузера (F12) доступен `window.__orda`:
`__orda.openChest()` — открыть сундук, `__orda.levelUp()` — получить уровень,
`__orda.G` — всё состояние игры, `__orda.sim({ hero: 'knight' })` — бот прогоняет забег
без отрисовки и возвращает, сколько продержался (так проверяется баланс). В собранной версии этого нет.
